### 诊断判定口径（v2 迭代）

所有结论由统一判定引擎 `js/diagnosis.js` 计算（唯一事实源），矩阵 / 雷达 / 统计卡片 / 诊断侧栏只渲染同一份结果，保证同一批数据在各处得到一致结论。

1. **成熟度分级**（L0~L3，按综合得分对照入档线）
   - L0 未入档 / L1 阶段1在建 / L2 阶段2达标 / L3 阶段3标杆
2. **差距阈值按阶段分别给出**：差距 = 该阶段标杆分 − 现状得分；阶段1/2/3 各有独立的「达标 / 关注 / 显著差距 / 关键断层」分数线
   - 默认 `v2026.09 严格版`：阶段2 断层线 40 分、显著差距 26 分、达标 ≤8 分（阶段1/3 阈值不同，见面板「规则与自检」）
   - 历史 `v2025.02 宽松版` 保留用于复盘对比
3. **关键断层判定标准**（满足任一）
   - 目标阶段差距达到该阶段关键断层线；
   - 判定范围内（阶段1~2）该阶段评估数据缺失，且缺失策略为「从严」→ 按关键断层处理；「从宽」→ 按关注处理；两种策略均不允许判达标；
   - 部分指标缺失：断层档不升级，若原档为达标则降为关注。
   - 范围外（阶段3）无数据 → 标记「未参评」，不参与判定，画像 SOP/工具内容保留可读。
4. **缺数据 / 部分数据显式标注按哪一档处理**，矩阵单元格内写明依据，杜绝「一边关键断层、一边达标」。
5. **口径持久化**：选择保存在 localStorage，刷新或再次进入沿用最近一次设定；可一键恢复默认。
6. **历史结论不可改写**：首次进入建立只读基线快照；每次口径调整归档一次快照（最多保留 20 条），切换口径不回写旧结论；「历史结论」面板可查看每次的维度档位与断层数。
7. **一致性自检**：引擎每次计算输出 40+ 项断言（档位与断层标记一致、叙事断层与判定集合一致、标杆分单一来源、差距算术一致等），结果可在「规则与自检」面板查看。

### 技术栈

- 前端：HTML5 + CSS3 + JavaScript（无框架，原生 ES 类）
- 图表：ECharts 5.x
- 持久化：localStorage（口径设置 + 历史结论快照）

- 设计风格：Cyberpunk/Vaporwave (深空黑 + 霓虹紫/激光粉)
